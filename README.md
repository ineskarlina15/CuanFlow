# CuanFlow

## Personal Finance Management System

CuanFlow adalah sistem manajemen keuangan pribadi berbasis Fullstack Java dan React.

## Roles

- USER
- ADMIN

## Architecture

CuanFlow menggunakan arsitektur Microservices yang terdiri dari:

1. API Gateway
2. Auth User Service
3. Finance Service
4. Notification Service

## Technology

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Spring Cloud Gateway

### Database
- PostgreSQL
